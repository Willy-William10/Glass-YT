# 🧊 GlassYT

A liquid glass theme for YouTube.

GlassYT changes the look of YouTube with glass effects, blur, transparency, custom colors, fonts, and other UI changes. It's still a work in progress, so some things might look a little weird or break after YouTube updates.

## ✨ Features

* Liquid glass / transparent UI
* Blur and glass effects
* Custom themes and colors
* Custom fonts
* Glass-style video cards
* More customization coming soon

## 🌐 Support

* **Edge** — Available
* **Firefox** — Available
* **Opera** — Coming soon
